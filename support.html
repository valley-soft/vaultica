Common questions

Quick answers

Where does Vaultica store my information?

Vaultica stores its workspace in the local Windows application-data area. Managed attachments and automatic recovery snapshots are local. Manual or scheduled backups are written only to locations you select.

Does Vaultica require an account or cloud connection?

No. Version 1.0.0 has no Vaultica account system or cloud synchronization. Some actions you initiate—such as opening a web link, map, email address, or phone number—are handed to the appropriate external Windows application.

What should I do before uninstalling?

Create and verify an encrypted backup if you need to retain the workspace. The installer can remove application files while retaining local user data, or remove local Vaultica data when you explicitly choose that option.

Can ValleySoft recover a forgotten PIN?

ValleySoft cannot access your PIN or encrypted content. Global PIN recovery works only if you created and retained the offline recovery kit beforehand. Separate per-note PINs cannot be recovered.

Which imports are supported?

Vaultica previews supported plain text, Markdown, common HTML documents, and CSV data before importing. Complex interactive web pages, scripts, applications, and unsupported content are rejected rather than imported as unreadable notes.
